## Required Build

Build a project using Qwen models available on Qwen Cloud and fit at least one track. Track 1, MemoryAgent, is the best fit for this workspace.

MemoryAgent emphasis:

- persistent memory across sessions
- remembering preferences and experience
- timely forgetting of stale information
- retrieval under limited context windows
- increasingly accurate decisions over multi-turn interaction

## Submission Surface

Expected Devpost assets:

- working project
- Qwen Cloud usage proof
- description and screenshots
- demo video, target under 3 minutes
- public or reviewable code if required by the final submission form
- track selection

## Winning Strategy

Build `RuleMemory`: a prize-hunting MemoryAgent that monitors contest sources, stores official rules and stale assumptions, routes tasks to Codex/Claude/Gemini/Hermes/local models, and produces submission readiness packets.

Judges should see:

- Qwen model calls are central, not decorative.
- Memory improves decisions across sessions.
- The agent catches stale rules and timezone errors.
- It produces practical artifacts: issue board, checklist, demo script, and risk report.

## Agent Assignments

- Research agent: keep Devpost/Qwen resource deltas current.
- Implementation agent: build minimal app, memory schema, retrieval, and demo path.
- Verification agent: check Qwen API smoke, source freshness, and video script.
- Story agent: explain why memory, forgetting, and provenance matter.
